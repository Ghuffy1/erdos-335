# Mathematical proof of the Erdős 335 classification

Will Howe, Grant Huffman, Jensen Kohlmeyer, and Liam Kruer

The result characterizes arbitrary pairs of positive-density subsets of the positive integers whose literal sumset has ordinary density equal to the sum of the two input densities. The stronger formulation separates the modular boundary case, the parallel Bohr-interval case, the two-periodic-template case, and the single sparse-section case.
